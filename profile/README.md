## Nezumo

Nezumo brings together a collaborative infinite canvas, browser and desktop
applications, WebAssembly rendering, presentations, and real-time
synchronization in one open ecosystem.

- [Website](https://nezumo.ru)
- [Open Nezumo](https://app.nezumo.ru)
- [Source code](https://github.com/OctaHive/nezumo)
- [Backend](https://github.com/OctaHive/nezumo-server)
